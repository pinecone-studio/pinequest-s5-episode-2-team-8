# Naadamy багш model: fine-tune туршилт

Зорилго: Монгол өв соёлын (Наадам, бөх гэх мэт) асуултад хариулдаг жижиг model. Llama 3.2 3B + LoRA (Unsloth), Google Colab T4.

**Төлөв: туршилт. Model одоогоор тоглоомд ашиглахад бэлэн БИШ.** Хүүхдэд буруу баримт хэлэх эрсдэлтэй.

## Файлууд
- `naadamy_finetune.py`: QLoRA 4-bit сургалт, GGUF (q4_k_m) export. Colab дээр ажиллуулна.
- `naadamy_model_test.py`: base model-уудыг 10 Монгол асуултаар шалгана.
- `naadamy_data_train.jsonl`: 257 асуулт-хариулт (system/user/assistant).
- `results_base_*.md`: base model шалгалтын үр дүн (гараар үнэлэх).
- `review_not_in_md.md`: UNESCO-ийн тэмдэглэлд (`naadam_unesco_medeelel.md`) баттай байхгүй байж болзошгүй 64 хос. Шалгах шаардлагатай.

## Үр дүн
**Base model (fine-tune-гүй), 10 асуулт:** Llama 3.2 3B, Qwen 2.5 3B, Gemma 3 4B бүгд Монгол хэлээр утгагүй эсвэл зохиосон хариулт өгсөн (хуурамч "1789 он"-д баримт зохиосон).

**Fine-tune #1** (rank 16, 3 epoch): train loss 0.756 -> 0.506, val loss 0.830 -> 0.676. Шалгалтын 4 асуултад (сургалтад орсон ч) бүгд буруу.

**Fine-tune #2** (rank 64, 8 epoch): val loss хамгийн бага нь epoch 3 (0.535), дараа нь өсч (epoch 6: 0.591) overfit болсон. train loss epoch 6 дээр 0.07.

| Epoch | Train loss | Val loss |
|---|---|---|
| 1 | 0.693 | 0.753 |
| 2 | 0.545 | 0.567 |
| 3 | 0.322 | 0.535 |
| 4 | 0.184 | 0.539 |
| 5 | 0.212 | 0.576 |
| 6 | 0.071 | 0.591 |

## Дүгнэлт ба дараагийн алхам
- 3-4B model-уудын Монгол хэлний суурь чадвар сул; жижиг dataset-ээр fine-tune хийхэд баримт тогтохгүй, overfit болно.
- Өгөгдлийн баримтыг эх сурвалжтай нь тулгах (`review_not_in_md.md`).
- Тоглоомд ашиглахаас өмнө сургалтад ороогүй асуултаар шалгах (алхам D).
- Өөр сонголт: том model-ийг (cloud API) баталгаатай баримтаар хангах.
