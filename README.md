# Naadamy — Монгол өв соёлоо хамтдаа сурцгаая

**Pinequest · Pinecone Academy · Сэдэв: "Ирээдүйгээ тохируулъя — Эрүүл мэнд, боловсрол, ур чадварт тэгш хүртээмж" (Fine-Tune for the Future)**

Naadamy бол хүүхэд, гэр бүл, найзууд **Монголын өв соёлыг хамтдаа сурдаг** тоглоом. Апп нээгдэнгүүт шууд **Нутаг** пиксел тосгон руу орно. Хажууд чинь **Басар** хэмээх монгол банхар AI нохой үргэлж дагаж явж, асуусан бүхэнд хариулж, Монголын түүх, Нууц товчооны асуулт хариулт өгнө. Өв соёлын сургуульд **монгол гэр барих, цагаан идээ хийх, гэрийн ёс заншил, Нууц товчооны үлгэр**-ийг тоглож сураад, сурснаа гэр бүлээрээ бодит амьдрал дээр хийнэ.

> Ээж, аав нь "Тоглохоо больчих" гэхэд хүүхэд "Ээж ээ, хамтдаа монгол гэр барьцгаая!" гэж хариулдаг болох нь бидний зорилго.

## Ажиллуулах

Суулгах, бүтээх (build) алхам шаардлагагүй. Энэ хавтас дотроос:

```bash
node server.js
# дараа нь http://localhost:8000 хаягийг нээнэ
```

Mac дээр `start.command`, Windows дээр `start.bat` файл дээр давхар дарж ч асааж болно. Сервер ижил Wi-Fi-д холбогдсон утас, компьютерээс нээх хаяг болон QR кодыг хэвлэж харуулна. Node.js-ээс өөр юу ч суулгах шаардлагагүй.

Утсан дээр хуудсыг нээгээд "Нүүр дэлгэцэд нэмэх" (Add to Home Screen)-ийг сонгоно. Анх ачаалсны дараа интернэтгүйгээр ажиллана.

### 🐕 Басар AI-г асаах (сонголттой)
Басар түлхүүргүй үед ч **офлайн мэдлэгээрээ** (47 асуулт, 34 хариулт, сонирхолтой баримтууд) бүрэн ажиллана. Жинхэнэ AI ухаантай болгох бол:

1. https://console.anthropic.com хуудаснаас API түлхүүр авна.
2. `.env.example` файлыг `.env` нэртэй хуулж, `ANTHROPIC_API_KEY=` мөрөнд түлхүүрээ бичнэ.
3. `node server.js`-ийг дахин асаана. Терминалд `Basar AI: on (claude-opus-5-5)` гэж гарна.

- Түлхүүр **зөвхөн сервер дээр** хадгалагдана. Хөтөч, утас руу хэзээ ч илгээгдэхгүй. `.env` файл git-д орохгүй.
- Анхдагч загвар нь `claude-opus-5-5`. Өөр загвар хэрэглэх бол `.env`-д `BASAR_MODEL=...` гэж бичнэ.
- Зардлыг хамгаалахын тулд нэг төхөөрөмж минутад 10 орчим, бүх сервер өдөрт 1500 асуулт (`BASAR_DAILY_LIMIT`) хүртэл асууна.
- Сервер ажиллахгүй, интернэт тасарсан, эсвэл хязгаарт хүрсэн үед Басар автоматаар офлайн мэдлэг рүүгээ шилжинэ.

## Xcode, бүртгэл, лиценз шаардлагагүй

Naadamy бол энгийн вэб апп буюу PWA (Progressive Web App) юм. Үүнийг бүтээх, ажиллуулах, танилцуулах, суулгахад Xcode, Android Studio, Apple Developer бүртгэл, Google Play бүртгэл эсвэл ямар нэг төлбөртэй лиценз **хэрэггүй**.

- **Бүтээх хэрэгсэл хэрэггүй.** Зөвхөн HTML, CSS, JavaScript ашигласан. Хөрвүүлэх (compile) зүйл байхгүй, `npm install` хийх шаардлагагүй.
- **Гуравдагч талын сан ашиглаагүй.** Фонтууд `assets/fonts` хавтсанд багтсан, дуу авиаг кодоор үүсгэдэг. Апп өөрөө гадны сервер рүү хүсэлт илгээдэггүй. Цорын ганц үл хамаарах зүйл нь Басар AI: та түлхүүр тохируулсан үед Басарт асуусан асуулт манай сервер дамжин Claude руу очно.
- **Апп дэлгүүр хэрэггүй.** Утсанд хөтчөөс шууд суулгана:
  - **iPhone (Safari):** Хуваалцах товч → "Add to Home Screen".
  - **Android (Chrome):** цэс ⋮ → "Install app" эсвэл "Add to Home screen".
  Ингэсний дараа өөрийн дүрс тэмдэгтэй, бүтэн дэлгэцээр нээгдэж, офлайн ажиллана.

### Утсанд үнэгүй байршуулах
Офлайн горим болон дуу хоолой бичих функц **HTTPS** (эсвэл `localhost`) хаяг шаарддаг. Утсанд ашиглахын тулд хавтсыг дараах үнэгүй байршуулах үйлчилгээний аль нэгэнд тавина. Аль нь ч төлбөртэй багц, лиценз шаардахгүй:
- **Netlify Drop**: төслийн хавтсыг app.netlify.com/drop хуудас руу чирж оруулна.
- **GitHub Pages**: хавтсыг GitHub репозиторид оруулаад, тохиргооноос нь Pages-ийг асаана.
- **Cloudflare Pages** эсвэл **Vercel**: репозиторийг үнэгүй багцаар холбоно.

Нэг Wi-Fi сүлжээнд хурдан турших бол дотоод серверийг ажиллуулаад утсан дээрээ `http://<компьютерийн-IP>:8000` хаягийг нээнэ. Энэ аргаар офлайн кэш болон микрофоноос бусад бүх зүйл ажиллана.

## Агуулга

### Нэвтрэх, бүртгүүлэх
Хөдөлгөөнт пиксел тал нутаг (гэр, давхиж буй унага, хонь, гүйж буй Басар)-ийн дэвсгэр дээр хүүхэд:
1. **Нэрээ** бичнэ (Басар асууна).
2. **Насаа** сонгоно (3–18).
3. **Сахиус амьтнаа** сонгоно: хурдан морь, тэмээ, бүргэд, цоохор ирвэс, Бөртэ чоно, хонь, ямаа, сарлаг, цаа буга, үнэг, зурам, мазаалай. Амьтан бүр нэг сонирхолтой баримттай.
4. **3 нууц зураг**-аа сонгож профайлаа хамгаална (заавал биш). Үсэг уншиж сураагүй хүүхэд ч санахад хялбар. Мартвал том хүн математикийн асуулт бодоод арилгана.

Нэг төхөөрөмж дээр олон хүүхэд тус тусын профайлтай байж, "Нэвтрэх" хэсгээс өөрийгөө сонгоно.

### 🎨 Дүрээ бүтээх (ястан, нутаг, хувцас)
Бүртгүүлсний дараа Нутаг руу орохоос өмнө:
1. **Ястнаа сонгоно:** Халх, Казах, Буриад, Дөрвөд, Баяд, Захчин, Торгууд, Өөлд, Урианхай, Цаатан, Дархад, Хотгойд, Дарьганга, Барга, Үзэмчин, Хотон, Мянгад, Тува. Ястан бүрийн тухай баримт гарна.
2. **Төрсөн нутгаа сонгоно:** тухайн ястны голлон амьдардаг аймгууд эхэнд гарна (жишээ нь Казах бол Баян-Өлгий, Ховд; Цаатан бол Хөвсгөл). Бусад аймаг эсвэл Улаанбаатарыг ч сонгож болно.
3. **Хувцаслана:** ястны уламжлалт малгай (казах, буриад, ойрад, үслэг, монгол), дээлийн өнгө, арьсны өнгө.
4. Төрсөн нутгийнх нь байгалийн зурагтай мэндчилгээ гарч, Нутагт дээд буланд **📍 аймаг · ястан** тэмдэг үргэлж харагдана.

### 🐕 Басар: монгол банхар AI найз
- Нутагт **үргэлж хажууд чинь** дагаж явна. Зогсоход хажууд чинь сууна. Хааяа "Вуф! Мэдэх үү?" гэж сонирхолтой баримт хуваалцана.
- Басар дээр дарах, 🐕 товч эсвэл **B** товчоор чат нээгдэнэ. **Монголоор ч, англиар ч** асууж болно: Басар асуултын хэлээр нь хариулна.
- **Юу ч асууж болно:** шинжлэх ухаан, байгаль, тоо бодлого, гэрийн даалгавар… Дуртай сэдэв нь Монголын өв соёл тул боломжтой үед түүнтэй холбоно. Гэрийн даалгаварт шууд хариу өгөхийн оронд ойлгоход нь тусална.
- Интернэтгүй үед ч өв соёлын асуултад хариулж, **энгийн тооны бодлого** ("7 x 8", "15 хасах 4") бодно.
- **Асуулт хариулт:** 6 сэдвээс (Түүх, Нууц товчоо, Монгол гэр, Цагаан идээ, Наадам, Ёс заншил) сонгоход 4 хувилбартай асуулт өгч, хариулсны дараа тайлбарлана. Зөв хариулт бүр Нутагт зоос, XP өгнө.
- **Хүүхдэд аюулгүй:** хувийн мэдээлэл асуудаггүй, хүүхдийн насанд тохирсон энгийн хэлээр 2–4 өгүүлбэрээр хариулна, түүхийг үнэн зөвөөр хэлж, мэдэхгүй бол "эмээ, өвөөгөөсөө асуугаарай" гэж зөвлөнө. Халуун сүү, зуух, хурц зүйлийг том хүнтэй хамт хэрэглэхийг сануулна.
- Хариулт бүр **AI** эсвэл **офлайн** гэсэн тэмдэгтэй тул эх сурвалж нь ойлгомжтой.

### 📚 Өв соёлын сургууль
Нутгийн **Сургуулийн гэр**-т ороход эсвэл 📖 товчоор нээгдэнэ. Хичээл бүр хөдөлгөөнт пиксел зурагтай: алхам бүрт гэр босч, сүү буцалж, үлгэрийн зураг солигдоно.

| Хичээл | Тоглож сурах зүйл | Гэр бүлээрээ хийх бодит ажил |
|---|---|---|
| ⛺ Монгол гэр барих | Шал → хана дэлгэх → хаалгыг урагш → тооно, багана → унь хатгах → эсгий → цагаан бүрээс → бүслүүр | Картон, шүдний чигчлүүр, даавуугаар бяцхан гэр барих |
| 🥛 Цагаан идээ хийх | Үнээ саах → сүүг халихгүй буцалгах → самарч өрөм гаргах → бүлээн болтол хөргөх → хөрөнгө хийх → дулаан боох → ааруул шахах, наранд хатаах | Гэртээ жинхэнэ тараг исгэх |
| 🙏 Гэрийн ёс заншил | Гэрийн дотоод зураг дээр хоймор, гал голомт, эрэгтэй ба эмэгтэй талыг олох, босго, нар зөв, багана | Эмээ, өвөөгөөсөө ёс заншил асууж, Дурсамжийн номонд бичих |
| 📜 Нууц товчооны үлгэр | Бөртэ чоно ба Гуа марал, Алан гуагийн таван сум, бяцхан Тэмүжин ба Өэлүн эх, Сорхон шар, 1206 оны Их хурилдай | Таван мөчрөөр эв нэгдлийн туршилт хийх |
| 🐑 Таван хошуу мал | Морь, үхэр, тэмээ, хонь, ямаа: айраг, эсгий, ноолуур, говийн хөлөг | Ахмадуудаас ямар мал маллаж байсныг асуух |
| 🥟 Цагаан сар | Бууз чимхэх, ул боовыг сондгой давхраар өрөх, битүүн, хадаг барьж золгох | Гэр бүлээрээ бууз чимхэж, золгох дадлага хийх |
| 🎻 Морин хуур ба уртын дуу | Хөөрхөн Намжилын домог, хоёр утас, уртын дуу, хөөмий, биелгээ, ёохор | Гэр бүлээрээ монгол хөгжим сонсож, бүжиглэх |
| 🦴 Шагай наадам | 4 тал (морь, тэмээ, хонь, ямаа), шагай хаях, морь уралдуулах, шагай харваа | Жинхэнэ шагайгаар морь уралдуулах |
| 🏆 Эрийн гурван наадам | Бөхийн өмсгөл, гарьдын бүжиг, хүүхэд унаач, айргаар цацах, "уухай" | Гэртээ жижиг наадам зохиох |

- Хичээл бүр **Басарын 3 асуултаар** төгсөнө (AI эсвэл офлайн асуултын сангаас).
- Дараа нь **"Одоо бодит амьдрал дээр"** карт гарна: хүүхдийн хэлэх үг ("Ээж, аав аа, хамтдаа монгол гэр барьцгаая!"), хэрэгтэй зүйлс, алхмууд. Том хүн баталгаажуулахад гэр бүлийн +5 од, зоос, XP өгнө.
- **"Монгол гэр барих" хичээлийг дуусгасны дараа л Нутагт өөрийн гэрээ барих эрх нээгдэнэ.** Жинхэнэ малчид гэрээ өөрсдөө барьдаг шиг.

### ✍️ Монгол бичгийн академи
Нутгийн зүүн талын ногоон дээвэртэй **академид** (эсвэл "Сурах" хэсгээс) **Бичээч багш** монгол бичиг заана.
- **Багш үзүүлнэ:** үсэг дээрээс доош бичигдэж буйг харуулна. Монгол бичгийг дээрээс доош, мөрийг зүүнээс баруун тийш бичдэг, үсэг бүр "нуруу"-нд өлгөөтэй, титэм, шүд, гэдэс, сүүлтэй гэдгийг заана.
- **Хуруу эсвэл тачпадаараа даган бичнэ:** утас, таблет дээр хуруугаар, компьютер дээр тачпад эсвэл хулганаар бичнэ.
- **Пиксел хэв маяг:** үсгийг тоглоомын пиксел хэв маягаар зурдаг ч жинхэнэ монгол бичгийн хэлбэрээ хадгална.
- **Зөв бичсэн эсэхийг шалгана:** жинхэнэ үсгийн хэлбэртэй (Noto Sans Mongolian фонт) харьцуулж, үсгийг хэр бүрхсэн, шугамаасаа гарсан эсэх, дээрээс доош бичсэн эсэхийг хэмжиж 1–3 од өгнө. Алдсан бол яг юу дутсаныг хэлнэ.
- **Санаж бичих:** загваргүйгээр санаж бичээд 🧠 тэмдэг авна.
- **27 хичээл:** 7 эгшиг (а, э, и, о, у, ө, ү), 12 үе (на, ба, ма, ла, са, ха, га, та, да, ча, жа, я), 8 анхны үг (гэр, морь, ээж, аав, нар, ус, нохой, монгол). Өмнөхөө бичвэл дараагийнх нь нээгдэнэ.

### 🛂 Аймгийн паспорт
Улаанбаатараас эхлээд Монголын 21 аймгаар дараалан аялна: Төв, Хэнтий, Дорнод, Сүхбаатар, Дорноговь… Баян-Өлгий, Увс. Аймаг бүрт:
- **Тухайн нутгийн байгалийн пиксел зураг** (уул, нуур, элсэн манхан, галт уул, тайга, хот).
- **Алдартай газрууд:** жишээ нь Хөвсгөл нуур, Хорго галт уулын тогоо (Архангай), Хонгорын элс, Баянзаг (Өмнөговь), Эрдэнэ Зуу (Өвөрхангай), Таван богд (Баян-Өлгий).
- **Түүх:** жишээ нь Чингис хаан Хэнтийн Дэлүүн болдогт төрсөн, 1923 онд Баянзагаас үлэг гүрвэлийн өндөг олдсон.
- Тухайн нутагт амьдардаг ястнууд.
- **🚌 Жинхэнээсээ аялах:** "Аялах" товч дарахад тухайн аймгийн байгалиар (уул, цасан оргил, нуур, гол ба гүүр, ой, говийн хад, элсэн манхан, хот, тариалан) бүтээгдсэн **бүтэн дэлгэцийн** газрын зураг нээгдэнэ, баруун дээд буланд жижиг газрын зураг бий. Үзвэр бүр жинхэнэ төрхөөрөө зурагдсан: Тэрэлжийн Мэлхий хад, Цонжин болдогийн Чингис хааны морьт хөшөө, Хустайн тахь, Хархорумын чулуун яст мэлхий, Эрдэнэ Зуугийн суварган хэрэм, Орхоны хүрхрээ, Хорго галт уулын тогоо, Баянзагийн улаан хад ба үлэг гүрвэлийн өндөг, цаатны урц, буган хөшөө, бүргэдчин гэх мэт. Автобусны буудлын дэргэд жуулчны гэр бааз бий. Аймаг бүрт: тухайн нутгийн мал (говьд тэмээ, ямаа; хангайд сарлаг; Хөвсгөлд цаа буга; дорнодод цагаан зээр) бэлчиж, дээр нь E дарвал тухайн малын тухай хэлнэ. Хашаатай **малчин айл** нутгийн сонирхолтой баримт ярьж, нутгийн хоол ундаагаар дайлна (говьд хоормог, Увсад чацарганы шүүс, Баян-Өлгийд казах баурсак, Ховдод тарвас). **Овоо**, аймгийн төв ба талбайг бичсэн **самбар**, тухайн нутгийн мод ургамал (шинэс, хус, улиас, заг), нуурын эргийн зэгс, хотын гэр хороолол, тогоруу, хун, бүргэд нисч, үүлний сүүдэр нүүнэ. Шар тугтай 3 үзвэрээр алхаж очоод тухайн газрын тухай уншина. Дараа нь тухайн нутгийн ястны хувцастай **нутгийн хөтөч** түүхийг ярьж, асуулт асууна. Зөв хариулбал **тамга** авч, автобусаар дараагийн аймаг руу шууд явж болно. Өөрийн нутаг "Миний нутаг" тэмдэгтэй.

### 🌳 Ургийн мод: Долоон үеэ мэд
Монголчууд "долоон үеэ мэддэг байх ёстой" гэдэг. Хүүхэд аавын болон ээжийн талын 7 үеийг (Би, Аав/Ээж, Өвөө/Эмээ, Элэнц, Хуланц, Улунц, Өлөнц) аав, ээж, өвөө, эмээгээсээ асууж бөглөнө. Хүн бүрийн нэр, төрсөн он, нутаг, түүх, хэнээс асуусныг бичнэ. **Мөчир бүр нэг од** гэрэлтүүлж, бүтэн үе бөглөвөл нэмэлт од өгнө. Ургийн овгоо ч бичнэ. Мэдээлэл зөвхөн төхөөрөмж дээр хадгалагдана.

### 🍃 Дөрвөн улирал
Нутагт улирал **өдөр бүр** солигдоно (хавар → зун → намар → өвөл), тиймээс хүүхэд дөрвөн улирлыг хэдхэн өдөрт мэдэрнэ. Өвөл зөөлөн цас орж (тосгон тод харагдсаар), намар навч унаж, хавар цэцгийн дэлбээ нисч, хурга төрнө. Улирал бүрийн тайлбарт: Монголд хэдэн сард болдог, малчид аль бууцанд (хаваржаа, зуслан, намаржаа, өвөлжөө) байж юу хийдэг, сонирхолтой баримт ("Улаанбаатар дэлхийн хамгийн хүйтэн нийслэл"), түүх уламжлал ("есөн ес"), Нутгийн улирлын тусгай даалгавар (+50% шагнал). Жинхэнэ Монголд яг одоо ямар улирал байгааг ч харуулна.

### 👨‍👩‍👧 Хамтдаа сурах
Хичээл эхлэх болон Басарын асуулт хариулт тоглох бүрт **"Хэнтэй хамт сурах вэ?"** гэж асууна:
- **Ганцаараа:** өөрөө дадлага хийнэ.
- **Гэр бүлтэйгээ:** гэр бүлийн гишүүдээс 1–3 хүн сонгоно. Алхам бүр дээр "Ээжийн ээлж" гэж ээлжлэн тоглож, унших алхмыг нэг нь чангаар уншина. Шагнал +50%, гэр бүлийн +2 од.
- **Найзуудтайгаа:** найзуудынхаа нэрийг нэмж, хэн илүү мэдэхийг өрсөлдөнө.
Төгсгөлд хүн бүрийн оноог харуулна. Хэнтэй хамт сурсан нь эцэг эхийн самбарт бүртгэгдэнэ.

### 🏅 Амжилтууд
Сурах, гэр бүл ба найз, Нутаг, Наадам гэсэн 4 ангиллаар 40 гаруй амжилт бий (жишээ нь "Гэрийн эзэн", "Найзуудтайгаа сурсан", "Түрүү морь", "Мэхний мастер", "Заан"). Амжилт нээгдэх бүрт мэдэгдэл гарч, хүүхэд "Амжилт" цэснээс ахицаа харна.
**Эцэг эхийн самбар** дээр: авсан амжилтууд огноотойгоо, хичээл бүрээс **юу сурсан** (гол санаанууд), хэнтэй хамт сурсан, Басарын 6 сэдвийн асуултад хэдэн зөв хариулсан, сүүлийн үйл ажиллагаа.

### 🏡 Нутаг: олон хүн хамт тоглох тосгон
Stardew Valley-гаас санаа авсан, монгол соёлтой 2D пиксел тосгон. Бүх зураг кодоор пиксел бүрээр зурагдсан өөрсдийн бүтээл.

- **Хамтын цэцэрлэг:** нэг өрөөний бүх хүн нэг цэцэрлэгт тарьж, усалж, хураана. Монголд ургадаг 7 ургамал.
- **Загасчлах:** алгана, цурхай, зэвэг, хадран (хамгаалагдсан тул буцааж тавина).
- **Наадмын дэлгүүр:** дээл, малгай, хадаг, тэжээвэр (хурга, банхар гөлөг, ботго…), тавилга.
- **Өөрийн монгол гэр:** гэр барих хичээлээ дуусгаад гэр хороололд гэр барьж, өнгийг нь сонгож, тавилгаар чимнэ. **Гэр дотроо ороход бүтэн дэлгэцээр нээгдэнэ.** Жинхэнэ монгол гэр шиг: улбар шар хана, униуд, тэнгэр харагдах тооно, хээтэй хоёр багана, голд нь зуух, хойморт шүтээн, гэр бүлийн зураг. Баруун тал (эрэгтэй хүний тал) эмээл, хөхүүртэй; зүүн тал (эмэгтэй хүний тал) аяга тавагны шүүгээ, усны савтай. Тавилга бүртэй харилцана: тулгандаа сүүтэй цай чанах, хөхүүрт айраг бүлэх, хоёр баганын ёс, тооно нарны цаг болдгийг сурах, орондоо унтаж амрах (усны сав дүүрнэ), авдраа нээж цуглуулгаа үзэх, морин хуур тоглох (жинхэнэ аялгуу эгшиглэнэ), ширдэг дээр Басартай сууж үлгэр сонсох, шагай хаях (дөрвөн морь буувал шагнал), ширээн дээрх ааруул идэх, хойморт суух. Найзууд чинь гэрт чинь орж зочилж болно.
- **👵 Эмээгийн гэр (ёс заншил):** Эмээ гэртээ урьж, хүүхэд босгыг алхаж давах, мэндлэх, нар зөв явах, цайг баруун гараараа авах, зочны суудал олох, баярлалаа гэж гарахыг хийнэ. **Буруу хийвэл шийтгэхгүй**, эмээ зөөлнөөр тайлбарлаад дахин оролдуулна. Нэг ч алдаагүй бол тусгай амжилт. Хөдөө өсөөгүй хүүхдүүдэд яг хэрэгтэй зүйл.
- **🧑‍🌾 Нутгийн хүмүүс:** Малчин Батбаяр (бэлчээр), Загасчин Дорж өвөө (гүүр), Тариачин Сарнай эгч (цэцэрлэг), Багш Оюун (сургуулийн гэр), Уяач Ганбаатар (морины уяа), Мэргэн Тулга ах (сурын талбай). Хүн бүр 3 даалгаврын цувралтай: хонь илбэх, загас барих, тарих, хичээл дуусгах, аймагт аялах, уралдах, харвах гэх мэт. Толгой дээр нь "!" бол шинэ даалгавар, "?" бол шагнал авахад бэлэн. Цуврал дуусгавал Монголын өв соёлын сонирхолтой баримт хэлж өгнө.
- **🏹 Сур харваа:** сурын талбайд 3 үе, үе бүрт 4 сум. Эхлээд өнцгөө, дараа нь хүчээ сонгож, салхийг тооцно. Бай онох бүрт шүүгчид "Уухай!" гэж дуулна. Үе ахих тусам бай холдож, салхи хүчтэй болно. Буруу харвавал "дутлаа/хэтэрлээ" гэж заана. 6 онвол Мэргэн, 9 бол Гарамгай мэргэн, 12 бол Улсын мэргэн цол.
- **Бөхийн барилдаан:** засуултай уулзаж, Наадамд барилдаж Начин, Харцага, Заан, Гарьд, Арслан, Аварга цол авна. Найзтайгаа шууд барилдана.
  - **7 мэх:** Түлхэх, Татах, Гадуур дэгээ, Дотуур дэгээ, Ташаадах, Хөл шүүрэх, Өргөж хаях. Мэх бүр дараагийн 3-ыг давж, өмнөх 3-д дийлддэг. "Мэхний ном"-оос мэх бүрийн тайлбарыг уншина.
  - **Даваа ахих тусам хэцүү:** хүчний зүү хурдан болж, ногоон хэсэг нарийсна, өрсөлдөгч таны их хэрэглэдэг мэхийг таньж сөрөх мэх хэрэглэнэ, 7-р давааноос 3 унагаалт хэрэгтэй. Нэг мэхийг дараалан давтвал хүч сулардаг.
- **🐎 Морь унах:** гудамжны зүүн талын **морины уяа**-наас 5 зүсний (хээр, хар, цагаан, зээрд, саарал) морь сонгож Нутгаар чөлөөтэй давхина. Морьтой үед хурдан явж, найзууд чинь таныг морьтой харна. 🐎 товчоор буух.
- **🏁 Морин уралдаан:** шинэ замаар хотыг тойрсон уралдааны зам бий. Наадмын жинхэнэ ангиллаар (Даага, Шүдлэн, Хязаалан, Соёолон, Их нас, Азарга) 1–3 тойрог уралдана. Эхний гуравт орвол дараагийн ангилал нээгдэнэ. **"Чү!"** товч (эсвэл Shift) морийг давхиулж тэсвэрийг зарцуулна. Морь чинь уралдаан бүрийн дараа хурд, тэсвэр нэмэгдэж дасгалжина. Тайлбарлагч хэн тэргүүлж байгааг хэлнэ. Төгсгөлд бүх унаачийн байр, цагийг харуулж, түрүү морийг айргаар цацах, айргийн тав, баян ходоодны уламжлалыг заана.
- **Овоо:** овоог тахиж, ёс заншлын талаар сурна.
- **Өдрийн даалгавар:** Басараас асуулт асуух, асуултад зөв хариулах, хичээл дуусгах, гэр бүлтэйгээ бодит ажил хийх, тарих, загасчлах гэх мэт.
- **Хөдөлгөөн:** WASD/сум товчоор 8 чиглэлд алхана, дэлгэц дээр дарахад очно. **Shift дарж байвал гүйнэ** (морьтой үед морь давхина, утсанд 🏃 товч). Гүйхэд хүч 🍖 зарцуулагдана. **Space дарвал үсэрнэ** (найзууд чинь ч харна, морьтой үед морь харайна), **E товч** ойролцоох зүйлтэй харилцана. Утсан дээр ⤒ товч үсрүүлнэ.
- **🍽️ Хоол, ундаа:** 🍖 товч эсвэл гэрийн ширээнээс бууз, хуушуур, хорхог, цуйван, гурилтай шөл, борц, өөрийн тарьсан ногоо, ааруул, боорцог, өрөм, тараг, баурсак, сүүтэй цай, айраг, хоормог, чацарганы шүүс, ус идэж уух. Хоол бүр хүч нэмж, өөрийн түүхтэй. Гэртээ цагаан идээ, ундаа үнэгүй, хөхүүрээс айраг бүлж ууна. 8 төрөл амсвал "Амтлагч" амжилт.
- **🗺️ Жижиг газрын зураг:** зүүн дээд буланд Нутгийн зураг байна: та (улаан), найзууд (цагаан), даалгавартай хүмүүс (шар), өөрийн гэр. Дарвал томорно, том зураг дээр газар сонговол тийшээ алхана.

### "Хиймэл оюун орлож чадахгүй" онцлогууд
- **Басар заана, гэр бүл хийнэ.** AI нохой мэдлэг өгдөг ч гэрийг ээж, аавтайгаа хамт барина. Хичээл бүр дэлгэцээс гадна дуусна.
- **Басар "эмээгээсээ асуу" гэдэг.** Мэдэхгүй зүйлээ ахмадуудаас асуухыг урамшуулна.
- **Дурсамжийн ном.** Эмээ, өвөөгийн ярьсан ёс заншил, түүх, дуу хоолойг бичиж хадгална. Бичлэгүүд зөвхөн төхөөрөмж дээр.
- **Эцэг эхийн самбар.** Хүүхэд аль хичээлийг сурсан, аль бодит ажлыг гэр бүлээрээ хийсэн, Басарын асуултад хэдэн зөв хариулсан, ямар амжилт авсныг харуулна.

### Тэгш хүртээмж
- Интернэтгүй хөдөө орон нутагт ажилладаг офлайн PWA. Басар ч офлайн мэдлэгтэй.
- Хуучин, хямд утсан дээр ажиллана. Монгол хэл үндсэн, англи хэл рүү сольж болно.
- Зар сурталчилгаагүй. Профайл, ахиц зөвхөн төхөөрөмж дээр хадгалагдана.
- Том үсэг, хөдөлгөөн багасгах горимтой.
- **Шударга үнэ:** Нутаг, бүх хичээл, Басарын офлайн мэдлэг үүрд үнэгүй. Сарын 3,900₮-ийн Гэр бүлийн багц Басар AI-г нээх бөгөөд тус бүр хөдөөгийн нэг хүүхдэд үнэгүй эрх олгоно.

```
.github/workflows/     GitHub Actions (шалгалт, GitHub Pages-д нийтлэх)
```

### Шинэ хичээл нэмэх
`js/learn/lessons.js` доторх `LESSONS` жагсаалтад нэг объект нэмнэ: `id`, `icon`, `title`, `desc`, `scene` (`ger`, `idee`, `inside`, `story`), `topic` (Басарын асуултын сэдэв), `steps` болон `family`. Алхмын төрлүүд: `learn`, `story`, `pick` (сонгох), `tf` (зөв/буруу), `tap` (олон дарах), `hold` (дараад барих), `timing` (цагаа олж дарах), `zones` (зураг дээр байрлал олох). Шинэ код бичих шаардлагагүй.

## Хамт тоглох (нэг Wi-Fi сүлжээнд)
1. Нэг компьютер дээр серверийг асаана:
   - **Mac:** `start.command` файл дээр давхар дарна.
   - **Windows:** `start.bat` файл дээр давхар дарна.
   - Эсвэл терминалд: `node server.js`
   (Node.js-ийг https://nodejs.org-оос үнэгүй суулгана.)
2. Сервер Wi-Fi хаяг (жишээ нь `http://192.168.1.25:8000`) болон **QR код** хэвлэнэ. Найзууд утасныхаа камераар уншуулахад шууд нээгдэнэ.
3. Нутагт дээд буланд байгаа холболтын товчийг дарахад **урилгын QR код** гарна. Энэ QR нь өрөөний кодыг агуулдаг тул уншуулсан хүн шууд ижил өрөөнд орно.
4. Анхдагч өрөө нь `NUTAG`. Гэр бүл, анги тусдаа тоглох бол нууц код (жишээ нь `BAT25`) сонгоно.

**Найзууд холбогдож чадахгүй бол:**
- Бүгд яг ижил Wi-Fi-д холбогдсон эсэхийг шалгана.
- Сургууль, зочны Wi-Fi ихэвчлэн төхөөрөмжүүдийг хооронд нь холбодоггүй. Ийм үед утасны **hotspot** асааж, бүгд түүнд холбогдоно.
- 8000 порт завгүй бол сервер автоматаар 8001, 8002… руу шилжиж, шинэ хаягаа хэвлэнэ.
- **Бие биеэ харахгүй байвал өрөөний кодоо шалгаарай.** Хүн бүр ижил өрөөний кодтой байх ёстой. Хэрэв серверт өөр өрөөнд хүн байвал Нутгийн холболтын товч улаанаар анивчиж `(+2)` гэж харуулна. Дарахад **"Үндсэн Нутаг руу орох"** товч гарч, нэг дарахад бүгдтэй нийлнэ.
- Нэг профайлыг хоёр цонхонд нээвэл сүүлд нээсэн нь үлдэж, өмнөх нь "өөр цонхонд нээгдлээ" гэж мэдэгдээд зогсоно.
- Mac дээр анх асаахад "node сүлжээний холболт хүлээн авах уу?" гэж асуувал **Allow (Зөвшөөрөх)** дарна. Үгүй бол бусад төхөөрөмж холбогдож чадахгүй.
- Netlify, GitHub Pages зэрэг үнэгүй статик хостинг дээр сервер ажилладаггүй тул хамт тоглох боломжгүй, зөвхөн ганцаараа горим ажиллана.

Сервергүй үед (жишээ нь GitHub Pages) Нутаг ганцаараа горимоор ажиллаж, цэцэрлэг утсан дээрээ хадгалагдана.

## Арын хөгжим
Апп 22 ширхэг 8-бит адал явдлын дуутай (нийт 50 орчим минут). Бүгд **CC0 (нийтийн өмч)** лицензтэй, OpenGameArt.org-оос авсан тул ямар ч зорилгоор, төлбөртэй багцад ч чөлөөтэй ашиглаж болно. Зохиогчдын нэрс "Бидний тухай" хуудсанд харагдана.

- Дуунууд холилдон тоглогдож, хооронд нь зөөлөн шилжинэ. Богино дууг 2–3 удаа давтаад дараагийнх руу шилжинэ.
- Хэрэглэгч анх дэлгэцэд хүрэхэд эхэлж, апп арын горимд ороход зогсоно.
- Нутагт ♪ товчоор асааж унтраана. Эцэг эх самбараас дууны хэмжээг тохируулна.
- Дуунуудыг утсанд хөнгөн байлгахын тулд AAC (`.m4a`, 56 kbps, моно) болгож, дууны түвшинг тэнцүүлсэн. Нийт хэмжээ 15 MB орчим.

Шинэ дуу нэмэх бол файлаа `assets/music/`-д хийгээд `assets/music/playlist.json`-д нэмнэ:

```json
{ "file": "song.m4a", "title": "Дууны нэр", "artist": "Зохиогч", "license": "CC0", "source": "https://...", "repeat": 1 }
```

## Хүүхдийн аюулгүй байдал
- Нутагт бичгээр чатлах боломжгүй. Зөвхөн бэлэн найрсаг үг, эможи ашиглана.
- Басарын AI-д зөвхөн асуулт, хүүхдийн нэр, нас илгээгдэх бөгөөд сервер тэдгээрийг хадгалдаггүй. Системийн заавар нь хувийн мэдээлэл асуухгүй, аюултай сэдвээс татгалзаж, гунигтай хүүхдийг том хүнтэй ярихыг уриалахыг шаарддаг. Claude татгалзвал Басар эелдгээр өөр сэдэв санал болгоно.
- Зөвхөн ижил өрөөний кодтой хүмүүс бие биеэ харна. Сервер бүх мэдээллийг шалгаж цэвэрлэж, мессежийн тоог хязгаарладаг.
- Сервер зөвхөн өрөөний цэцэрлэг, гэрийг хадгална (`data/rooms.json`). Хүүхдийн ахиц зөвхөн төхөөрөмж дээр.

## Автомат шалгалт ба нийтлэл (GitHub Actions)

`.github/workflows/ci.yml` нь push болон pull request бүрт автоматаар ажиллана:

1. **JavaScript-ийн бичлэгийн шалгалт.**
2. **Файлын шалгалт** (`tests/check-assets.mjs`): бүх файл байгаа, офлайн кэшэд орсон, гадны сервер рүү хүсэлт илгээдэггүй эсэх.
3. **Хөтчийн шалгалт** (`tests/smoke.mjs`): бүртгүүлэх, нууц зургаар нэвтрэх, Нутаг, Басарын монгол ба англи хариулт, тооны бодлого, 4 хичээл, гэр бүлтэйгээ сурах, найзтайгаа асуулт хариулт, морь унах, морин уралдаан, 7 мэх, амжилт, эцэг эхийн тайлан.
4. **Олон тоглогчийн шалгалт** (`tests/multiplayer.mjs`): хоёр тоглогч хамт тарих, услах, ярих, морь унах, гэр барих, барилдах.
5. **Басар AI-н шалгалт** (`tests/basar-api.mjs`): хуурамч Claude API ашиглан түлхүүр хөтөч рүү гарахгүй, зөв загвар, бүтэцтэй асуулт, татгалзлыг зөв зохицуулдаг, түлхүүргүй үед офлайн горимд ордгийг шалгана. Жинхэнэ түлхүүр шаардлагагүй.
6. **GitHub Pages-д нийтлэх.** `main` шинэчлэгдэх бүрт аппыг нийтэлнэ (Басар тэнд офлайн мэдлэгээр ажиллана).

```bash
node tests/check-assets.mjs && node tests/basar-api.mjs
npm install --no-save puppeteer-core@22.15.0 && node tests/smoke.mjs && node tests/multiplayer.mjs
```

## Шүүгчдэд үзүүлэх дараалал
1. Аппыг нээж, хөдөлгөөнт тал нутгийн дэвсгэр дээр **бүртгүүлнэ**: нэр, нас, сахиус амьтан, 3 нууц зураг.
2. Шууд **Нутаг** руу орж, **Басар** хажууд дагаж явахыг харуулна. Басар дээр дарж "Нууц товчоо гэж юу вэ?" гэж асуугаад, дараа нь англиар "What is Naadam?" гэж асууна.
3. Гэр хорооллын хоосон газар очиход "Эхлээд гэр барьж сур!" гэж гарна. Тэндээс **Монгол гэр барих** хичээлийг тоглож гэрээ алхам алхмаар босгоно.
4. Хичээлийн төгсгөлийн **"Ээж, аав аа, хамтдаа монгол гэр барьцгаая!"** картыг үзүүлж, бяцхан гэрийн бодит загварыг (урьдчилан хийсэн бол) харуулна.
5. Нутаг руу буцаж **өөрийн гэрээ барина**. Хоёр дахь утсаар найз нь нэгдэж гэрт зочилно.
6. **Цагаан идээ** хичээлийг "Гэр бүлтэйгээ" сонгож тоглоно: алхам бүрт ээлж солигдож, төгсгөлд оноо гарна.
7. **Морины уяа**-наас морь унаж, **морин уралдаан**-д оролцоно. Дараа нь Наадмын талбайд 7 мэхээр барилдана.
8. **Амжилт** цэсийг харуулна.
9. **Эцэг эхийн самбар**-аас хүүхдийн амжилт, юу сурсан, хэнтэй хамт сурсныг харуулна.
10. **Бидний тухай / Шударга үнэ** хуудсаар төгсгөнө.
