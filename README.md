# Naadamy — Монгол өв соёлоо хамтдаа сурцгаая

**Pinequest · Pinecone Academy · Сэдэв: "Ирээдүйгээ тохируулъя — Эрүүл мэнд, боловсрол, ур чадварт тэгш хүртээмж" (Fine-Tune for the Future)**

Naadamy бол хүүхэд, гэр бүл, найзууд **Монголын өв соёлыг хамтдаа сурдаг** тоглоом. Тоглоомыг нээмэгц **Нутаг** пиксел тосгон руу орно. Хажууд чинь **Басар** хэмээх монгол банхар AI нохой үргэлж дагаж явж, асуусан бүхэнд хариулж, Монголын түүх, Нууц товчооны асуулт хариулт өгнө. Өв соёлын сургуульд **монгол гэр барих, цагаан идээ хийх, гэрийн ёс заншил, Нууц товчооны үлгэр**-ийг тоглож сураад, сурснаа гэр бүлээрээ бодит амьдрал дээр хийнэ.

> Ээж, аав нь "Тоглохоо больчих" гэхэд хүүхэд "Ээж ээ, хамтдаа монгол гэр барьцгаая!" гэж хариулдаг болох нь бидний зорилго.

## Юунаас бүрдэх вэ

- **Тоглоом (клиент):** Unity **6000.6.7f1** дээр бичсэн (`unity/`). Android, PC болон хөтөч (WebGL) дээр ажиллана. Зураг нь урьдчилан зурсан PNG (`unity/Assets/Resources/Art`, `unity/Tools/art/*.py` скриптээр үүсгэсэн) ба `Px.cs` кодоор зурсан пиксел зургаас бүрдэнэ. Дуу авиан эффектийг (`Sfx.cs`) кодоор үүсгэдэг.
- **Сервер:** Node.js (`server/`), HTTP болон WebSocket. Хамт тоглох өрөө, гэр бүлийн нэвтрэлт, үүлэн хадгалалт, Басар AI-г үйлчилнэ.
- **`web/`:** одоо вэб апп биш. Phaser болон хөтчийн UI хуучин хувилбарын хамт устсан (PR #82). Серверт хэрэгтэй гурван файл л үлдсэн: `web/js/village/rules.js` (тоглоомын дүрэм), `web/js/village/world.js` (тосгоны газрын зураг), `web/js/qr.js`. Эдгээрийг сервер өөрөө ачаалдаг бөгөөд хөтчид файлаар **хэзээ ч** тараадаггүй.

Unity талын дэлгэрэнгүй (удирдлага, build, файл бүрийн үүрэг): [unity/README.md](./unity/README.md). Клиент ба серверийн WebSocket/HTTP протокол: [docs/PROTOCOL.md](./docs/PROTOCOL.md).

## Серверийг ажиллуулах

Node.js 20 эсвэл түүнээс дээш хувилбар хэрэгтэй (`package.json`-ийн `engines`). Репозиторийн үндсэн хавтас дотроос:

```bash
npm ci
npm start        # = node server/server.js
```

- Анхдагч порт нь **8000**. `PORT=3000 npm start` гэж орчны хувьсагчаар эсвэл `node server/server.js 3000` гэж аргументаар солино (хоёулаа байвал `PORT` давуу). Порт завгүй бол сервер өөрөө дараагийн порт руу (8001, 8002…) шилжиж, хаягаа хэвлэнэ. Хамгийн ихдээ 10 удаа оролдоно (8010 хүртэл).
- Терминалд ижил Wi-Fi-н хаяг (терминалд ажиллуулбал QR код ч) хэвлэгдэнэ.
- Асаасан эсэхийг шалгах: `http://localhost:8000/api/hello` нь `{"naadamy": true, ...}` гэж хариулна.
- `DATABASE_URL` тохируулаагүй бол өрөө, гэр бүлийн мэдээллийг `data/` хавтас (эсвэл `DATA_DIR`) дахь JSON файлд хадгална. Өгөгдлийн сан хэрэггүй.
- Unity-ийн WebGL build (`unity/Builds/WebGL`) байвал сервер түүнийг файлаар үйлчилнэ. Байхгүй бол (Render дээр ийм) зөвхөн API болон `/ws` хариулна.

### Тохиргооны хувьсагчид

`.env.example` файлыг `.env` нэрээр хуулж бөглөж болно (`.env` git-д орохгүй). Бүгд сонголттой. **`.env` файлаас зөвхөн** `DATABASE_URL` болон Басарын хувьсагчид (`ANTHROPIC_API_KEY`, `BASAR_MODEL`, `BASAR_DAILY_LIMIT`, `ANTHROPIC_BASE_URL`) уншигдана. `PORT`, `DATA_DIR`, `CORS_ORIGINS` зэргийг зөвхөн процессын орчноос авна (ж: `PORT=3000 npm start`).

| Хувьсагч | Утга |
|---|---|
| `PORT` | Серверийн порт (анхдагч `8000`) |
| `DATABASE_URL` | PostgreSQL холболт. Хоосон/байхгүй бол JSON файл ашиглана |
| `DATA_DIR` | JSON файлууд хадгалагдах хавтас (анхдагч `data/`) |
| `CORS_ORIGINS` | API-г дуудахыг зөвшөөрөх **нэмэлт** вэб хаягууд, таслалаар тусгаарлана (ж: `https://a.example,https://b.example`) |
| `ANTHROPIC_API_KEY` | Басар жинхэнэ AI болно. Түлхүүргүй үед офлайн мэдлэгээрээ ажиллана |
| `BASAR_MODEL` | Басарын загвар (анхдагч `claude-opus-5-5`) |
| `BASAR_DAILY_LIMIT` | Серверийн процесс бүрийн UTC өдрийн асуултын дээд хязгаар (анхдагч `1500`). Сервер дахин асахад тэглэгдэнэ |
| `ANTHROPIC_BASE_URL` | Anthropic API-ийн өөр хаяг (анхдагч `https://api.anthropic.com`) |
| `NODE_ENV=production` эсвэл `RENDER` | Прокси (Render)-ийн `x-forwarded-for` хаягийг итгэнэ. Render дээр өөрөө тохирно |
| `HEARTBEAT_MS` | Холболт шалгах ping-ийн мөчлөг (анхдагч `20000` мс) |

**CORS_ORIGINS:** хөтчөөс API-г дуудаж болох хаягууд нь `https://naadamy-unity.vercel.app` (болон `naadamy-unity-…vercel.app` preview), локал сүлжээний хаяг (`localhost`, `127.0.0.1`, `192.168.x.x`, `10.x.x.x`; зөвхөн `http://`) болон `CORS_ORIGINS`-д бичсэн хаягууд. Бусад сайтын хуудаснаас ирсэн хүсэлтийг хөтөч хориглоно.

### 🐕 Басар AI-г асаах (сонголттой)
Басар түлхүүргүй үед ч **офлайн мэдлэгээрээ** бүрэн ажиллана. Жинхэнэ AI ухаантай болгох бол:

1. https://console.anthropic.com хуудаснаас API түлхүүр авна.
2. `.env.example`-ийг `.env` нэртэй хуулж, `ANTHROPIC_API_KEY=` мөрөнд түлхүүрээ бичнэ.
3. Серверийг дахин асаана.

- Түлхүүр **зөвхөн сервер дээр** хадгалагдана, тоглоом руу хэзээ ч илгээгдэхгүй.
- Зардлыг хамгаалахын тулд хязгаарыг **IP хаяг** тус бүрээр тооцно: минутад ~10, 15 минутад 30 асуулт. Интернэтийн (Render) сервер дээр нэг Wi-Fi-н төхөөрөмжүүд нэг IP-тэй тул нэг хязгаарыг хуваалцана. Өдөрт серверийн процесс бүрт `BASAR_DAILY_LIMIT` (1500) хүртэл.
- Сервер ажиллахгүй, интернэт тасарсан, эсвэл хязгаарт хүрсэн үед Басар автоматаар офлайн мэдлэг рүүгээ шилжинэ.

## Unity тоглоомыг ажиллуулах

1. Unity Hub → **Add project from disk** → `unity/` хавтсыг сонгоно. Editor хувилбар: **6000.6.7f1**.
2. Эхний нээлтэд `Naadamy/Set up project` өөрөө ажиллаж `Assets/Scenes/Nutag.unity`-г үүсгэнэ.
3. **Play** дарна.

**Серверийн хаяг.** Тоглоом анхдагчаар Render дээрх сервер рүү холбогдоно (`unity/Assets/Scripts/Family.cs` доторх `Family.HOSTED` = `https://pinequest-s5-episode-2-team-8.onrender.com`), тиймээс хүүхэд хаяг бичих шаардлагагүй. Өөр сервер (жишээ нь гэрийн Wi-Fi дээрх `npm start`) ашиглах бол тоглоомын ☰ → **Тохиргоо** (Settings) дотор хаягийг бичнэ (ж: `192.168.1.10:8000`). Тохиргоо дахь хаяг `HOSTED`-ээс давуу эрхтэй. Хөтөч дэх (WebGL) хувилбар Басар AI болон хамт тоглоход `https://` хаяг шаарддаг.

WebGL хувилбар https://naadamy-unity.vercel.app дээр байрлана (`main` дээр `unity/` өөрчлөгдөхөд `.github/workflows/unity-web.yml` build хийж Vercel рүү нийтэлнэ). Android APK, Windows, WebGL build хийх алхам, удирдлагын товчлуурууд: [unity/README.md](./unity/README.md).

## Байршуулалт: Render + Supabase

Сервер нь Render дээр, өгөгдлийн сан нь Supabase (PostgreSQL) дээр ажиллана. Одоогийн хаяг: **https://pinequest-s5-episode-2-team-8.onrender.com** (`/api/hello` нь эрүүл мэндийн шалгалт).

1. Репозиторийг Render-тэй холбоод **New → Blueprint**-оор [render.yaml](./render.yaml)-ийг сонгоно. Энэ нь Singapore бүсэд `0.5 CPU / 512 MB` Node үйлчилгээ (`npm ci` + синтакс шалгалт, `node server/server.js`) болон `/var/data` дээр 1 GB persistent диск үүсгэнэ. Persistent диск нь Render-ийн **төлбөртэй** төлөвлөгөө шаарддаг тул төлбөр, бүсийг шалгаж баталгаажуулсны дараа deploy хийнэ.
2. Web Service-ийн **Environment**-д `DATABASE_URL`-ийг гараар оруулна (`render.yaml`-д утгыг нь бичээгүй, `sync: false`). Supabase-ийн **Session pooler** холболтын URL-ийг **5432 порттой** нь хэрэглэнэ. Сервер өрөөний бодит цагийн мэдээллийг PostgreSQL-ийн `LISTEN/NOTIFY`-аар солилцдог бөгөөд энэ нь session горимд л ажилладаг. Transaction pooler (6543) тохирохгүй, шууд холболт ихэвчлэн зөвхөн IPv6 тул Render дээр ажиллахгүй байж болно. `DATABASE_URL`-ийг хэзээ ч git-д оруулахгүй, нийтэд харуулахгүй.
3. `DATA_DIR` нь `render.yaml`-д `/var/data` гэж тохирсон.
4. Шинэ Blueprint deploy нь өөрийн хаяг авна (үйлчилгээний нэр `naadamy-team8`). Тэр хаягийг `Family.HOSTED`-д бичээд Unity-г дахин build хийнэ. Дээрх `pinequest-s5-episode-2-team-8.onrender.com` нь тусад нь үүсгэсэн үйлчилгээ.

**Анхаарах зүйл:**
- Үнэгүй (free) төлөвлөгөөнд удаан идэвхгүй байсны дараа сервер унтаж, эхний хүсэлт хэдэн арван секунд удаан байж болно (cold start). `render.yaml`-ын `0.5c-512mb` төлөвлөгөө диск бүхий төлбөртэй тул унтдаггүй.
- Хүснэгтүүд (`naadamy_rooms` гэх мэт) сервер анх асахад `CREATE TABLE IF NOT EXISTS`-ээр өөрөө үүснэ.
- `DATABASE_URL` байхгүй бол сервер өрөөг `DATA_DIR`-ийн JSON файлд хадгална. PostgreSQL эхлэхэд DB-д байхгүй өрөөнүүдийг хуучин JSON-оос импортолно.
- Серверт холбогдож чадахгүй үед тоглоом ганцаараа горимоор ажиллаж, ахиц төхөөрөмж дээрээ хадгалагдана.

## Хамт тоглох

- **Нэг Wi-Fi дээр:** нэг компьютер дээр `npm start` хийж, бусад төхөөрөмж дээр тоглоомын Тохиргоонд серверийн хаягийг бичнэ. Сервер терминалд ижил Wi-Fi-н хаяг (терминалд ажиллуулбал QR код ч) хэвлэнэ. Бүгд ижил **өрөөний кодтой** байвал нэг тосгонд (Нутаг) бие биеийгээ харна. Анхдагч өрөө `NUTAG`. Сургуулийн Wi-Fi төхөөрөмжүүдийг хооронд нь холбодоггүй бол утасны hotspot ашиглана. Mac дээр анх асаахад "node сүлжээний холболт хүлээн авах уу?" гэвэл **Allow** дарна, үгүй бол бусад төхөөрөмж холбогдож чадахгүй.
- **Интернэтээр:** Render дээрх сервер (дээрх хэсэг). Тоглоом анхдагчаар түүнд холбогдоно.
- **Гэр бүлийн нэвтрэлт:** том хүн гэр бүлийн код үүсгэж, хүүхэд бүрийг 3 нууц зурагтай нэмнэ. Хүүхэд өөр төхөөрөмж дээр кодоо оруулж, нэрээ сонгоод зурагнуудаа дарахад ижил дүр, зоос, XP, үүлэн хадгалалтаа авна. Дэлгэрэнгүй: [docs/PROTOCOL.md](./docs/PROTOCOL.md).

## Автомат шалгалт

Тестүүд `tests/` хавтсанд байна. Репозиторийн үндсэн хавтаснаас ажиллуулна. `DATABASE_URL=''` нь тестийг өгөгдлийн сангүй, JSON файлаар ажиллуулна:

```bash
DATABASE_URL='' node tests/basar-api.mjs          # Басарын API, түлхүүргүй үеийн офлайн горим
DATABASE_URL='' node tests/chat-persistence.mjs   # сүүлийн чат мессежүүд серверийг дахин асаахад хадгалагдах
DATABASE_URL='' node tests/family.mjs             # гэр бүлийн нэвтрэлт, үүлэн хадгалалт
DATABASE_URL='' node tests/ger-rules.mjs          # гэр барих дүрэм
DATABASE_URL='' node tests/learned.mjs            # гараар сурсан зүйлсийн дүрэм
DATABASE_URL='' node tests/room-store.mjs         # өрөөний хадгалалт: PostgreSQL шилжүүлэлт ба JSON
DATABASE_URL='' node tests/shared-presence.mjs    # олон серверийн нэг өрөө: байрлал, мэдэгдэл
```

> **Анхаар:** зөвхөн `family.mjs` болон `basar-api.mjs` жинхэнэ серверийг асааж, `DATABASE_URL`-ийг өвлөнө. `.env` дахь `DATABASE_URL` экспортлоогүй ч уншигдана, `DATABASE_URL=''` түүнийг дарна. Supabase руу заасан үед эдгээр тест өгөгдлийн санд мөр үлдээж болно. Бусад тест хуурамч pool эсвэл `''` ашигладаг, эсвэл өгөгдлийн сантай огт харьцдаггүй. Тиймээс дандаа `DATABASE_URL=''`-тэй ажиллуул.

## Хүүхдийн аюулгүй байдал

- Нийтийн `NUTAG` өрөөнд линк мэддэг хэн ч орж чадна. Өрөөний код нь нууц үг, баталгаажуулалт **биш**. Хүүхдийг том хүний хяналтгүйгээр үл мэдэгдэх хүнтэй тоглуулахгүй, гэр бүл тусдаа тоглох бол өөрийн өрөөний код сонго.
- Басар хувийн мэдээлэл асуудаггүй, хүүхдийн насанд тохирсон энгийн хэлээр богино хариулна. Мэдэхгүй бол мэдэхгүй гэдгээ хэлж, тохирвол гэр бүлээсээ асуухыг санал болгоно.
- Anthropic API түлхүүр болон `DATABASE_URL` зөвхөн серверийн орчинд хадгалагдана.
- Сервер хариулт бүрт аюулгүй байдлын header (толгой мэдээлэл: `nosniff`, `X-Frame-Options: DENY`, referrer-policy гэх мэт) нэмдэг, Басарын хүсэлтийг хаягаар хязгаарладаг.
